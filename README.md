# Biblioteca UniFecaf

Projeto acadêmico desenvolvido em HTML e CSS a partir de um protótipo de interface de biblioteca.

## Como executar

Abra o arquivo `index.html` em um navegador. O projeto não depende de servidor ou biblioteca externa.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos mantendo a estrutura de pastas.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O GitHub fornecerá o link público do site na seção Pages.
